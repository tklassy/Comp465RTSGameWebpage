Project Overview

An overview of the design and major systems of the COMP 465 real-time strategy game.

Game Concept

The project is a modern military real-time strategy game developed in Unity. The game combines traditional RTS base building and unit control with a larger emphasis on logistics, transportation, resource movement, and supporting military operations.

Vehicle Control

Vehicles are the primary controllable units. The Player can select individual vehicles or groups, issue movement commands, establish logistics routes, and construct buildings.

Selectable objects use Player, Enemy, and Neutral factions. Enemy and Neutral objects can be selected and inspected, while Player command systems only allow Player-owned units to receive orders.

Base Building

Buildings are placed on a 10×10 world grid using vehicle-based construction. Current structures include the Headquarters, Barracks, production buildings, maintenance facilities, and specialized resource warehouses.

Buildings can have health, selection information, faction ownership, and NavMesh obstacles without requiring combat capabilities.

Resources and Logistics

The economy currently includes Money, Food, Water, Fuel, Wood, Metal, and Electronics. Physical resources are stored in specialized warehouses and transported by cargo vehicles.

The resource interface tracks both warehouse storage and resources currently in transit. Destroyed cargo vehicles and warehouses automatically remove their contents from the displayed totals.

The long-term goal is for logistics to directly support construction, production, and combat operations.

Production and Manpower

Production buildings use reusable production queues. Individual units can require resources, manpower capacity, and construction time before they are spawned.

Produced units consume manpower while they exist and release that manpower when destroyed. Barracks increase the manpower cap and remove that additional capacity if the Barracks is destroyed.

The game supports temporary over-cap states. Existing units remain active if a Barracks is lost, but additional units cannot be produced until manpower usage falls back below the available cap.

Combat

Armed vehicles can automatically detect hostile Player or Enemy objects, rotate toward targets, fire weapons, deal damage, and destroy targets.

Faction ownership is independent from CombatUnit, allowing non-combat buildings to be valid combat targets without giving those buildings weapons.

Damaged units and buildings display world-space health bars with remaining health shown in green and missing health shown in red. Weapon fire currently uses visible yellow LineRenderer tracers.

Enemy Forces

Enemy vehicles use predefined waypoint routes and NavMesh navigation to travel toward the Player's base.

Enemy production is currently handled by a destructible enemy building. The building periodically spawns enemy vehicles and assigns them to the configured attack route. Destroying the production building stops future enemy vehicle spawns.

User Interface

The HUD provides resource totals, manpower, game time, selection information, health, cargo information, production progress, and command controls.

Health and production bars use reusable Simple UISprite-based displays that resize using anchors rather than Unity Filled Image rendering.

Planned Features

  • Dedicated Player and Enemy tanks
  • Tank production building
  • Player Attack and Attack-Move commands
  • Muzzle flashes, impacts, explosions, and destruction effects
  • Expanded enemy buildings and enemy AI
  • Construction sites requiring delivered resources
  • Import and export logistics systems
  • Minimap
  • Building and unit upgrades
  • Aircraft and helicopters
  • Improved road-based vehicle navigation
