Project Overview

An overview of the design and major systems of the COMP 465 real-time strategy game.

Game Concept

The project is a modern military real-time strategy game developed in Unity. The game combines traditional RTS base building and unit control with a larger emphasis on logistics, transportation, and resource movement.

Vehicle Control

Vehicles are the primary controllable units. The player can select individual vehicles or groups, issue movement commands, establish routes, construct buildings, and eventually issue direct combat orders.

Base Building

Buildings are placed on a grid using vehicle-based construction. Current structures include the Headquarters, Barracks, production buildings, maintenance facilities, and specialized resource warehouses.

Resources and Logistics

The economy currently includes Money, Food, Water, Fuel, Wood, Metal, and Electronics. Physical resources can be stored in specialized warehouses and transported by cargo vehicles.

The long-term goal is for logistics to directly support construction, production, and combat operations.

Production

Production buildings use reusable production queues. Individual units can require resources, manpower capacity, and construction time before they are spawned.

Combat

Combat vehicles can detect hostile units, rotate toward targets, fire weapons, deal damage, and destroy enemy vehicles.

Enemy forces can be spawned continuously and directed toward the player's base using predefined waypoint routes.

Planned Features

  • Dedicated tanks and additional combat vehicles
  • Player attack and attack-move commands
  • Improved muzzle flashes and weapon effects
  • Enemy buildings and expanded enemy AI
  • Construction sites requiring delivered resources
  • Additional logistics systems
  • Minimap
  • Building and unit upgrades
  • Aircraft and helicopters
  • Import and export systems
