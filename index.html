Vibe Coding Development Notice

Approximately 95% of the code in this project has been vibe coded, or some may say AI-assisted development.

AI tools are used throughout development to generate, troubleshoot, explain, refactor, and document code as the project evolves.

Purpose of the Project

The purpose of this project is to learn through the process of designing and building a functioning real-time strategy game. Development focuses on gaining practical experience with Unity, C#, software architecture, user interfaces, and the supporting systems those features depend on.

AI assistance is used as a learning and development tool throughout the project, allowing game-development concepts and systems to be explored, implemented, and understood through hands-on work.

Welcome

The project is a modern military RTS focused on vehicle control, base construction, logistics, resource management, and combat. Development is completed in individual work cycles, with major changes recorded on this website.

The Changelog combines development history and implementation documentation. Each change can be expanded to show additional information about how that system was designed and implemented.
