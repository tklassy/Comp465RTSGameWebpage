Completed Systems that are currently implemented and working

Vehicle Cargo System

Vehicles can carry physical resources using the reusable VehicleCargo system.

Load / Unload System

Vehicles can collect resources and transfer them through warehouse Shipping and Receiving points.

Resource Nodes

Physical resource nodes provide resources for logistics vehicles to collect.

Warehouses

Specialized warehouses store individual physical resource types.

Basic Resource Collection Loop

Vehicles can travel to a resource node, collect resources, return to a warehouse, unload, and repeat the route.

Logistics Routes

Persistent vehicle routes support repeated resource collection and delivery operations.

Additional Resource Types

The current economy includes Money, Food, Water, Fuel, Wood, Metal, and Electronics.

Selection and Information Panel

Selected vehicles, buildings, warehouses, and resource nodes display relevant information in the bottom HUD.

Building Placement

Buildings use a grid-based placement system with ghost previews, placement validation, and vehicle construction orders.

Production Queue

Production buildings can queue units using configurable build times, manpower requirements, and resource costs.

Manpower System

Units consume manpower capacity, while buildings such as the Barracks can increase the available manpower cap.

Enemy Attack Routes

Enemy vehicles can follow predefined waypoint routes using NavMesh movement between each waypoint.

Enemy Vehicle Spawning

Enemy bases can continuously spawn configurable vehicle prefabs at an adjustable interval.

Basic Vehicle Combat

Player and enemy combat vehicles can automatically detect hostile units, fire weapons, deal damage, and destroy targets.

Hitscan Tracers

Vehicle weapon fire can display a short LineRenderer tracer between the weapon muzzle and target.

HQ Quick Access

A HUD button can select the Headquarters and center the camera on it when clicked again.

Development Website

A project website now provides a homepage, changelog, documentation, project overview, and roadmap.

In Progress Systems currently being developed or expanded

Combat and Enemy Attacks

The basic combat loop is operational. Development will continue with dedicated combat vehicles, better enemy behavior, player attack commands, visual effects, and base attacks.

More Vehicles and Buildings

Continue expanding the current vehicle and building roster with dedicated military and logistics units.

UI Scaling and Layout

Continue refining HUD scaling, anchors, percentage-based panel sizing, and screen-resolution support.

Asset Updates

Continue replacing placeholder geometry with the current low-poly environment and vehicle/building assets.

Next Priorities Features planned for the next development cycles

Combat Vehicles

Add dedicated player and enemy tanks and expand vehicle weapon statistics such as damage, range, fire rate, and health.

Attack Commands

Add direct Attack and Attack Move commands to player combat vehicles.

Combat Effects

Add muzzle flashes, better tracers, explosions, and vehicle destruction effects.

Enemy Base Behavior

Expand the current enemy spawner into a more complete enemy base capable of continuously producing and sending attack forces.

Tank Production Building

Add a production building specifically for tanks and other combat vehicles using the existing BuildingProductionQueue.

Enable NavMesh for Built Roads

Update the runtime navigation system so player-built roads, bridges, and other traversable surfaces can affect NavMesh movement.

Minimap

Add a minimap showing the terrain, player units, buildings, resources, and enemy contacts.

Logistics and Economy Backlog Planned expansion of the logistics systems

Construction Sites

Replace instant final construction with temporary construction sites that require delivered materials before completion.

Construction Material Delivery

Allow trucks to automatically deliver only the amount of each resource still required by a construction site.

Construction Labor

Allow nearby vehicles to contribute construction progress, with dedicated construction vehicles providing a speed bonus.

Import / Export System

Expand the existing resource economy with Import and Export Warehouses connected to Shipping and Receiving.

Seven-Day Logistics Cycle

Process Headquarters orders and exports on a repeating seven-day game-time schedule.

Resource Tooltip Interaction

Allow individual warehouse and vehicle entries in resource tooltips to focus the camera on that object.

UI and Interface Backlog Planned interface improvements

Production Queue Visuals

Replace simple production queue text with visual queue boxes or unit icons.

Production Cost Display

Display build time, resource costs, and manpower requirements for the selected production option.

Main Menu

Add functionality to the existing Main Menu button and menu section.

Game Speed Controls

Add HUD controls for pause, normal speed, and accelerated game speeds.

Future Features Longer-term features and expansion ideas

Upgrades System

Add building and unit upgrades using progression levels such as Level I, II, and III.

Helicopters

Add aircraft using a separate movement system that does not rely on the ground NavMesh.

Additional Combat Units

Add tanks, armored vehicles, additional logistics vehicles, and other military unit types.

Advanced Enemy AI

Expand enemy behavior beyond fixed routes to include multiple attack routes, target priorities, and different attack groups.

Road Navigation Preference

Add a dedicated Road NavMesh Area so vehicles prefer roads when calculating paths.

Additional Map

Create another playable map and continue work toward supporting custom map or heightmap imports.

Map Development

Continue expanding terrain detail with roads, trees, hills, bridges, resource areas, bases, and strategic routes.
