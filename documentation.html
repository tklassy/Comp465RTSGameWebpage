October 19, 2026 Combat and Enemy AI

Headquarters Quick Access

A quick-access button was added to the bottom HUD to provide faster access to the player's Headquarters.

The first click searches the UnitSelectionManager for a selectable building with the Headquarters building type and makes it the active selection. If the Headquarters is already the only selected object, clicking the button again centers the RTS camera on it.

The RTSCameraController was updated with reusable focus methods, allowing both the new UI button and the existing Space-key behavior to use the same camera-centering logic.

Enemy Attack Routes

A predefined attack-route system was added to provide more reliable long-distance enemy movement.

An EnemyAttackRoute contains child waypoint objects arranged in Hierarchy order. EnemyRouteFollower moves a NavMeshAgent from one waypoint to the next until the final destination is reached.

This allows the developer to manually determine the overall strategic path while still allowing Unity's NavMesh system to navigate around smaller obstacles between waypoints.

Enemy Vehicle Spawning

EnemySpawner was created to continuously generate enemy forces.

The Unity Inspector can be used to select the enemy building prefab, vehicle prefab, building spawn location, vehicle spawn location, attack route, and vehicle spawn interval.

When a vehicle is instantiated, the spawner finds its EnemyRouteFollower component and assigns the configured attack route.

Combat Unit System

A reusable CombatUnit component was created for both player and enemy combat vehicles.

CombatUnit combines faction assignment, hostile target detection, weapon timing, weapon damage, targeting range, and optional turret rotation into a single component.

Units periodically search nearby colliders for objects with a SelectableHealth and CombatUnit component. Targets are filtered by faction, and the nearest hostile unit inside the configured range is selected.

Health and Destruction

Combat uses the existing SelectableHealth component rather than maintaining a separate combat health system.

Each weapon hit calls TakeDamage on the target. Vehicles with Destroy On Death enabled are destroyed when their health reaches zero and disappear from the battlefield.

Hitscan Tracers

A visible tracer was added to make automatic weapon fire easier to identify during gameplay.

Damage is still applied immediately using a hitscan-style system. A LineRenderer briefly displays a line between the vehicle's FirePoint and the target when the weapon fires.

Tracer width and duration are Inspector-adjustable so future weapons can use different visual characteristics.

October 14, 2026 Command and Production Refactor

Command System Refactor

The command interface was reorganized so the central CommandPanelManager only manages the generic 3×4 command grid and keyboard input.

Individual selectable objects now provide their own commands. HumveeCommands, HDTCommands, FuelTruckCommands, and building command scripts determine which commands appear for each selection.

Shared functionality is provided by VehicleCommandsBase and ProductionBuildingCommandsBase.

Reusable Vehicle Construction

VehicleConstruction was converted into a generic construction component.

Individual vehicle command scripts now contain references to the structures that vehicle is allowed to build. This prevents the central command system from containing references to every building in the game.

Building Production Queue

BuildingProductionQueue was created as a reusable production system for Headquarters and other production buildings.

Each production option can define its prefab, production time, manpower requirement, and physical resource costs. Resources and manpower are reserved or spent when production is queued.

Completed units spawn at the configured production point and can automatically move toward the building's rally point.

Selected Object Information

The bottom information panel was expanded to show reusable selection information for units, buildings, resources, health, cargo, and production.

Production buildings display the current item being built, percentage completion, progress bar, and queued production count.

October 8, 2026 Construction and Logistics

Grid-Based Construction

A 10×10 world grid was added for structure placement. GridManager converts world positions into grid coordinates, snaps structures to cell centers, and tracks occupied and reserved cells.

Building placement uses a ghost preview to show the intended structure before construction begins. Valid and invalid locations use different preview materials.

Vehicle Construction Orders

Buildings are constructed using player vehicles rather than appearing immediately when placed.

A vehicle receives a Build command and moves toward the selected construction location. Shift-click allows multiple construction orders to be placed into the vehicle's command queue.

Warehouses and Physical Resources

Physical resource storage was moved into specialized warehouse buildings.

Wood, Metal, Electronics, Fuel, Water, and Food can each be stored in warehouses configured for that resource type. Warehouse capacities and starting quantities are adjustable in the Inspector.

Vehicle Cargo

VehicleCargo allows logistics vehicles to physically transport resources between resource nodes and warehouses.

Vehicles can be configured to carry all resources or only a selected set of resources. Capacity is also configurable by vehicle type.

Logistics Routes

Persistent vehicle routes were added for repeated logistics operations.

Route creation allows the player to create waypoint paths that can include resource nodes and warehouse transfer points. Route markers remain associated with the vehicle and can be hidden when the vehicle is not selected.

Resource Interface

The top HUD was expanded to display Money and the total amount of each physical resource currently owned.

Physical totals include both resources currently stored in warehouses and resources currently being transported by vehicles. Hover information provides a breakdown of where each resource is located.

September 21, 2026 Initial RTS Systems

RTS Camera

The project began with an RTS-style camera supporting arrow-key movement, screen-edge scrolling, mouse-wheel zoom, and camera focusing on selected units.

NavMesh Vehicle Movement

Unity's NavMesh system was added to provide basic vehicle pathfinding across the RTS map.

The first controllable vehicle was a Truck using a NavMeshAgent for movement.

Unit Selection

UnitSelectionManager and UnitSelectionBox were created to support both individual click selection and traditional RTS drag-box selection.

Selectable objects use selection indicators that appear when the object is selected and disappear when deselected.

Headquarters

The Headquarters was introduced as the first selectable player building.

Early production functionality allowed the Headquarters to produce Trucks and send newly created vehicles toward a rally point.

Command Panel

A Warcraft-style 3×4 command grid was created using the QWER, ASDF, and ZXCV keyboard layout.

This interface became the foundation for the later dynamic command system used by individual vehicles and buildings.
