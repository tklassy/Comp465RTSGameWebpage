Development Changelog

A chronological record of features, fixes, and changes made during development of the COMP 465 RTS project.

Home Changelog Documentation Project Overview Roadmap
October 19, 2026 Combat and Enemy AI
  • Added an HQ quick-access button that selects the player's Headquarters and centers the camera when clicked again.
  • Added reusable camera focus functions so UI controls and the existing Space-key camera behavior can use the same system.
  • Added predefined enemy attack routes using manually placed waypoints and NavMesh movement between each route point.
  • Added an Inspector-configurable enemy spawner for selecting the enemy building prefab, vehicle prefab, attack route, and vehicle spawn interval.
  • Added a reusable CombatUnit system that handles factions, hostile target detection, weapon damage, firing intervals, and optional turret rotation.
  • Connected combat damage to the existing SelectableHealth system.
  • Enabled combat vehicles to disappear when their health reaches zero using Destroy On Death.
  • Added visible LineRenderer hitscan tracers between weapon fire points and targets.
October 14, 2026 Command and Production Refactor
  • Reworked the command system so the CommandPanelManager only manages the shared 3×4 command panel.
  • Added unit-specific command components such as HumveeCommands, HDTCommands, FuelTruckCommands, and production-building command scripts.
  • Added reusable VehicleCommandsBase and ProductionBuildingCommandsBase classes.
  • Refactored VehicleConstruction into a reusable construction component instead of storing individual building prefabs in the central command manager.
  • Added a reusable BuildingProductionQueue with production time, manpower requirements, and physical resource costs.
  • Added rally-point support to production buildings.
  • Added production progress and queue information to the selected object information panel.
  • Added SelectableInfoData and SelectableHealth components for reusable unit and building information.
  • Removed obsolete individual production wrapper scripts after converting production buildings to the reusable queue system.
October 8, 2026 Construction and Logistics
  • Added a 10×10 world grid for building placement and grid-cell occupancy tracking.
  • Added building ghost previews with valid and invalid placement feedback.
  • Added vehicle-based construction where the selected vehicle drives to the construction location before completing the building.
  • Added queued construction orders using Shift-click placement.
  • Added NavMeshObstacle carving to completed buildings while keeping placement ghosts non-blocking.
  • Added specialized resource warehouses for Wood, Metal, Electronics, Fuel, Water, and Food.
  • Added physical vehicle cargo and warehouse transfer points.
  • Added persistent vehicle logistics routes with visible route markers.
  • Added physical resource nodes that vehicles can load resources from.
  • Added the top resource display showing stored and in-transit physical resources.
  • Added resource hover information showing where stored and transported resources are currently located.
  • Added manpower capacity and Barracks-based manpower expansion.
September 21, 2026 Initial RTS Systems
  • Created the initial COMP 465 RTS Unity project and playable scene.
  • Added RTS camera movement using arrow keys and screen-edge scrolling.
  • Added camera zoom and Space-key camera focusing on selected units.
  • Added a baked NavMesh for vehicle movement.
  • Added the first controllable Truck vehicle.
  • Added single-click and drag-box unit selection.
  • Added visual selection indicators for selected units and buildings.
  • Added the Headquarters as the first selectable building.
  • Added early Headquarters vehicle production and rally-point functionality.
  • Added the first fixed 3×4 RTS command panel using QWER, ASDF, and ZXCV hotkeys.
